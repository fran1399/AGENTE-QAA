# Evidence Analysis

## Approach

EVIDENCE → OBSERVATION → INTERPRETATION → CONCLUSION

Avoid: EVIDENCE → ASSUMPTION → CONFIRMED

## Rules

- NO EVIDENCE = NO CONFIRMED RESULT
- Link each conclusion to specific evidence (with paths)
- Absence of evidence reduces confidence
- Distinguish direct vs circumstantial evidence
- Require reproducibility for critical conclusions when feasible
- State confidence (HIGH/MEDIUM/LOW)
- If insufficient: INSUFFICIENT_EVIDENCE
- Never claim validation without evidence
- Differentiate: tool called/requested → tool executed → execution_success → result obtained → result validated (do not infer success from attempt alone)
